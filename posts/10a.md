## Blog 10a – Real-Time Score Visualisation with WebSockets

My AT3 project is a p5.js-based visualisation that changes in real time based on the score of The Summer Games - the sports competition within my group of friends. The idea is that as teams score throughout the gmae, the animation changes shape, colour, and intensity. It's meant to feel like a living aura that reacts to community energy.

### Could I Use WebSockets?

The most obvious way to make this truly live would be to hook it up to a WebSocket connection.

Right now, the sketch just reflects static or manually entered data. But if I used WebSockets, I could stream score updates as they happen from a small input form or admin panel - and anyone watching the page would see the visualisation shift in real time on their own devices, without them having to input the goals themselves. That would make the project feel much more alive (lean into the magical aura vibe too), especially during match days.

I could also make a second version for a live screen during the games — maybe projected or even shown on instagram.

### What I'd Need to Learn

- How to set up a WebSocket server (Node.js + socket.io seem to probably the easiest starting point)
- How to send and receive messages from the server in p5.js (through the browser using JavaScript)
- Syncing visuals without duplicating or glitching effects
- Potentially building a small admin interface where someone can input scores that broadcast out to the visualiser

Right now my code is just local. This would mean hosting it properly somewhere that can handle persistent connections. I think I’d also need to learn about state management and handling disconnects.

### Why It’d Be Worth It

This would take the project from something that reacts to already known data to something that lives in the moment. It also turns it into a shared artefact, not just a personal one. You could open the page from anywhere and feel connected to the rest of the comp. That would have helped me last season as I was living in Melbourne and missed out on watching the games live, instead I could have pulled up the aura to feel connected.

### Mycelial Creativity and Live Scores

The idea of mycelial creativity fits really well here. A mycelial network is invisible, but deeply interconnected. That’s what this project could be: a digital fungal thread between people playing, watching, or just checking in.

The Summer Games already operates like a creative community. The visualiser becomes an output of that network whichi s shaped by everyone’s movement, effort, and competitiveness. Using WebSockets makes it even more mycelial. The project starts reacting in real time, growing and evolving with every small touch, just like a living system.

### Final Thoughts

I’m not totally sure I’ll have time to set this all up before the deadline, but I really want to try at least a simple version so I can share with everyone in Canberra. Even just one live score update triggering a shape change would be enough to show how much more alive the project could feel with websockets involved.
